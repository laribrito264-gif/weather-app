# 🌤️ Aplicativo de Previsão do Tempo 
## 📌 Sobre o projeto
Este é um aplicativo de previsão do tempo desenvolvido para praticar HTML, CSS e JavaScript.
O usuário pode pesquisar uma cidade e visualizar informações como:
- 🌡️ Temperatura
- ☁️ Condição do tempo
- 💧 Umidade
Os dados são obtidos por meio da API OpenWeather.
## 🚀 Tecnologias utilizadas 
- HTML5
- CSS3
- JavaScript
- OpenWeather API
- ## 🎯 Objetivo
- Este projeto faz parte do meu portfólio de estudos em Análise e Desenvolvimento de Sistemas, com o objetivo de praticar o consumo de APIs e a manipulação do DOM.
